# AutoTasks — Python Automation Portfolio

Repositório de projetos práticos desenvolvidos em **Python** com foco em automação de tarefas repetitivas, manipulação de dados, integração com serviços e desenvolvimento de soluções simples para problemas reais.

O objetivo é aplicar conceitos de desenvolvimento de software em projetos progressivamente mais completos, construindo um portfólio voltado para **automação e engenharia de software**.

---

## 🚀 Projetos

### 📁 Organizador de Arquivos

Automação para organização de arquivos em diretórios com base em seus tipos e regras definidas pelo programa.

O projeto foi desenvolvido utilizando **Python** e ferramentas de assistência por IA durante o processo de desenvolvimento.

**Conceitos aplicados:**

* Manipulação de arquivos e diretórios
* `pathlib`
* Estruturas condicionais
* Funções
* Tratamento de exceções
* Organização e modularização do código
* Automação de tarefas repetitivas

**Status:** ✅ Concluído

---

### 📧 Gmail Automation

Projeto de automação para interação com mensagens do Gmail utilizando a **API do Google**.

A proposta é automatizar operações relacionadas ao gerenciamento de e-mails, explorando integração com APIs externas e autenticação.

**Conceitos explorados:**

* Integração com API
* Autenticação OAuth 2.0
* Manipulação de dados
* Requisições a serviços externos
* Automação de tarefas
* Gerenciamento de credenciais

**Status:** 🚧 Em desenvolvimento

> O projeto ainda não está finalizado e será evoluído conforme novos conceitos de integração e automação forem estudados.

---

### 📊 Relatórios

Automação para processamento de registros e geração de informações a partir de dados armazenados em arquivos.

O projeto simula uma situação operacional em que informações precisam ser processadas e transformadas em relatórios de forma automática.

**Conceitos aplicados:**

* Leitura e escrita de arquivos
* Manipulação de CSV
* Processamento de dados
* Filtros e agregações
* Funções
* Tratamento de exceções
* Geração de relatórios

**Status:** ✅ Concluído

## ▶️ Execução

Clone o repositório:

```bash
git clone https://github.com/layserondon/Portifolio-AutoTasks-Python.git
```

Entre no diretório:

```bash
cd Portifolio-AutoTasks-Python
```

Para executar um projeto, acesse seu respectivo diretório e siga as instruções disponíveis em sua documentação.

Exemplo:

```bash
python nome_do_arquivo.py
```

Alguns projetos podem exigir dependências ou configurações adicionais.

## 🔐 Segurança
